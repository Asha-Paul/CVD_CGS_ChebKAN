# CVD_CGS_ChebKAN

## Project Description
This repository contains the implementation of Chebyshev Kolmogorov-Arnold Network (ChebKAN) models for cardiovascular disease prediction.

The project investigates different ChebKAN architectures, baseline machine learning models, conformal calibration, and model evaluation.

## Dataset
The study uses a publicly available cardiovascular disease dataset obtained from Kaggle.

The original dataset is not included in this repository. Please obtain it from the original source and follow its licence conditions.

## Project Components
- Data preprocessing and quality auditing
- Baseline machine learning models
- ChebKAN model implementations
- Conformal calibration
- External validation
- Statistical comparisons
- Performance evaluation
